# CLATTER demonstration samples

These sounds were synthesised by `scripts/make-samples.mjs` (noise, oscillators, envelopes and
filters): they contain no recordings and no third-party sample material. They are CLATTER's own
and are dedicated to the public domain under CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/). Run the script to regenerate them exactly.
